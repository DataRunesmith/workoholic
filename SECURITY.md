# Security Policy

## Supported versions

Only the latest code on the `main` branch is supported. Security fixes are
made there; older commits and forks do not receive patches.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, pull
requests or discussions.

Use GitHub's private vulnerability reporting instead:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Describe the problem, how to reproduce it, and its likely impact.

Do not include real secrets, tokens or personal data in the report.

## What to expect

- We aim to acknowledge a report within 7 days.
- We will investigate, keep you informed of progress, and tell you when a fix
  is available.
- Please allow time for a fix before any public disclosure. We are happy to
  credit you in the fix if you wish.
